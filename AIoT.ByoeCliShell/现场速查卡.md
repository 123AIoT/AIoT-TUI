# AIoT.ByoeCliShell 现场速查卡

> 适用：现场快速联调（.NET 10 / PowerShell）

---

## 1) 先确认支持能力

```powershell
dotnet run --project AIoT.ByoeCliShell/AIoT.ByoeCliShell.csproj -- list --format text
```

---

## 2) 最小闭环（本机模拟 + 本机读取）

### 终端A：启动 Modbus TCP 模拟器
```powershell
dotnet run --project AIoT.ByoeCliShell/AIoT.ByoeCliShell.csproj -- sim-run --protocol modbus.tcp --port 1502 --preloadAddress 100 --preloadValue 321 --type int
```

### 终端B：读取模拟器寄存器
```powershell
dotnet run --project AIoT.ByoeCliShell/AIoT.ByoeCliShell.csproj -- client-read --protocol modbus.tcp --endpoint modbus.tcp://127.0.0.1:1502 --address 100 --type int
```

### 终端B：写入后再读
```powershell
dotnet run --project AIoT.ByoeCliShell/AIoT.ByoeCliShell.csproj -- client-write --protocol modbus.tcp --endpoint modbus.tcp://127.0.0.1:1502 --address 100 --value 999 --type int
```

```powershell
dotnet run --project AIoT.ByoeCliShell/AIoT.ByoeCliShell.csproj -- client-read --protocol modbus.tcp --endpoint modbus.tcp://127.0.0.1:1502 --address 100 --type int
```

---

## 3) 常用协议连接模板

### Siemens S7
```powershell
dotnet run --project AIoT.ByoeCliShell/AIoT.ByoeCliShell.csproj -- client-connect --protocol siemens.s7 --endpoint "s7://192.168.1.10:102?plc=s1200&rack=0&slot=1"
```

### Modbus TCP
```powershell
dotnet run --project AIoT.ByoeCliShell/AIoT.ByoeCliShell.csproj -- client-connect --protocol modbus.tcp --endpoint modbus.tcp://192.168.1.20:502 --station 1
```

### Modbus RTU
```powershell
dotnet run --project AIoT.ByoeCliShell/AIoT.ByoeCliShell.csproj -- client-connect --protocol modbus.rtu --endpoint modbus.rtu://COM3?baud=9600&station=1
```

---

## 4) 批量探测（Browse）

### Modbus 区间
```powershell
dotnet run --project AIoT.ByoeCliShell/AIoT.ByoeCliShell.csproj -- client-browse --protocol modbus.tcp --endpoint modbus.tcp://192.168.1.20:502 --start 100 --count 10 --type int --format ndjson
```

### 指定地址列表
```powershell
dotnet run --project AIoT.ByoeCliShell/AIoT.ByoeCliShell.csproj -- client-browse --protocol siemens.s7 --endpoint "s7://192.168.1.10:102?plc=s1200&rack=0&slot=1" --addresses "DB1.0,DB1.2,M100" --type int --format json
```

---

## 5) 输出格式

- `--format json`：默认
- `--format ndjson`：一行一条，便于日志/流处理
- `--format text`：人工查看

---

## 6) 现场排错三步

1. `list` 看协议是否支持
2. 先跑本机闭环（sim-run + client-read）排除工具问题
3. 再接真实设备，检查 IP/端口/协议参数（plc/rack/slot、station、baud）

---

## 7) 高频参数备忘

- Siemens：`--plc s1200|s1500|s300|s400|s200|s200smart --rack 0 --slot 1`
- Modbus：`--station 1`
- RTU：`--baud 9600`
- 通用：`--type int|float|bool|string`
