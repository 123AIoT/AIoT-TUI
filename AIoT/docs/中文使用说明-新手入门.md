# AIoT 新手入门（TUI + CLI）

> 适用对象：第一次使用 AIoT 的工程师、测试、运维。  
> 目标：快速完成 **选协议 -> 建连接 -> 加点位 -> 读写/监控**。

---

## 1. 启动方式

在仓库根目录：

```powershell
dotnet build
dotnet run --project AIoT/AIoT.csproj
```

- 不带子命令时，默认进入 **TUI**。
- 查看 CLI 帮助：

```powershell
dotnet run --project AIoT/AIoT.csproj -- --help
```

### 1.1 打包为可执行文件（推荐交付方式）

项目已提供跨平台打包脚本：

- PowerShell：`scripts/publish.ps1`
- Bash：`scripts/publish.sh`

常用示例：

```powershell
# Windows PowerShell 下执行（默认打包 win-x64/linux-x64/osx-x64）
./scripts/publish.ps1

# 仅打包 Windows
./scripts/publish.ps1 -Rids win-x64
```

```bash
# Linux/macOS 下执行
./scripts/publish.sh

# 仅打包 Linux
./scripts/publish.sh --rid linux-x64
```

输出目录：`dist/<rid>/`，例如 Windows 可执行文件在：`dist/win-x64/AIoT.exe`。

## 2. TUI 快速上手（推荐新手）

## 2.1 打开连接对话框

菜单进入：`Connection -> Connect...`

## 2.2 选择协议（重点）

在 Connect 对话框中：

- 按 **Alt+P** 打开协议列表（或切到 `Pick` 按钮后回车）。
- 在弹窗里用方向键选择协议，回车确认。
- 返回 Connect 对话框后继续填写连接参数。

当前常用协议键：

- `opcua`
- `mqtt`
- `websocket`
- `modbus.tcp`
- `modbus.rtu`
- `siemens.s7`
- `melsec`
- `omron`
- `delta`
- `xinje`

## 2.3 填写 Endpoint 与协议参数

常见 Endpoint 示例：

- OPC UA：`opc.tcp://localhost:4840`
- MQTT：`mqtt://127.0.0.1:1883`
- WebSocket：`ws://127.0.0.1:8080/ws`
- Modbus TCP：`modbus.tcp://127.0.0.1:502`
- Modbus RTU：`modbus.rtu://COM3?baud=9600&station=1`
- Siemens S7：`s7://192.168.0.10:102?plc=s1200&rack=0&slot=1`

协议专用输入（在 Connect 对话框会按协议显示）：

- Modbus RTU：`baud` / `station`
- Siemens S7：`plc` / `rack` / `slot`
- MQTT：`clientId` / `qos` / `retain` / `topic`
- WebSocket：`subprotocol` / `address` / `header`

填写完后点 `Connect`。

## 2.4 增加/编辑/导入监控点位（重点）

连接成功后，在 **Monitored Variables** 区域操作：

- `A`：新增点位
- `E`：编辑选中点位
- `I`：批量导入点位
- `Delete`：删除选中点位

说明：

- 点位维护在 Monitored Variables 中，不在 Connect 对话框里。
- 新增/编辑点位时可设置地址、数据类型、长度（如 string/hex 常需长度）。

## 2.5 常用快捷键

- `Tab`：切换面板
- `W`：写值到选中变量
- `Space`：切换变量选中（用于 Scope/记录）
- `S`：打开 Scope
- `?`：帮助

## 3. CLI 快速上手（脚本/自动化）

基本语法：

```text
aiot <read|write|browse|monitor> <endpoint> ... [options]
```

源码运行等价：

```powershell
dotnet run --project AIoT/AIoT.csproj -- <read|write|browse|monitor> <endpoint> ... [options]
```

## 3.1 读取示例

```powershell
dotnet run --project AIoT/AIoT.csproj -- read opc.tcp://localhost:4840 "ns=2;s=Counter" --format json
```

## 3.2 写入示例（Modbus TCP）

```powershell
dotnet run --project AIoT/AIoT.csproj -- write modbus.tcp://127.0.0.1:502 100 true --protocol modbus.tcp --type bool --station 1 --format json
```

## 3.3 监控示例（WebSocket）

```powershell
dotnet run --project AIoT/AIoT.csproj -- monitor ws://127.0.0.1:8080/ws --protocol websocket --ws-address '$last' --count 3 --format ndjson
```

## 3.4 常用参数

- `--protocol <name>`：指定协议
- `--type <datatype>`：类型提示（bool/int/float/string/hex 等）
- `--format text|json|ndjson`：输出格式
- `--count <n>`：monitor 输出 n 条后退出
- `--interval <ms>`：监控间隔（适用场景下）

---

## 4. 推荐上手流程（新手）

1. 先用 TUI：Alt+P 选协议，填 endpoint，连通。  
2. 在 Monitored Variables 用 `A/E/I` 维护点位。  
3. 验证读写监控后，再用 CLI 固化成脚本。

## 5. 常见问题

### 5.1 看起来只能 OPC UA

请在 Connect 对话框按 **Alt+P** 打开协议列表选择其他协议。

### 5.2 连接后没有数据

- 检查点位地址是否正确
- 检查设备端是否有变化
- MQTT/WebSocket 注意其缓存/消息到达语义

### 5.3 写值失败

- 检查数据类型是否匹配（可加 `--type`）
- 检查点位是否可写
- 检查设备权限
